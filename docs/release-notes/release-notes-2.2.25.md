## FileTerm 2.2.25

FileTerm 2.2.25 updates the macOS build environment for current macOS system styling while retaining the existing minimum system version configuration.

### Highlights

- **macOS build environment**: Build Apple Silicon and Intel installers on macOS 26 runners so current macOS versions can use their native control styling. Keep the existing minimum system version configuration; the Apple Silicon binary still requires macOS 11 or later. macOS 15.7.9 users are invited to confirm title-bar button compatibility in the new build (related to #243).

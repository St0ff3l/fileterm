## FileTerm 2.2.14

修复 Windows 标题栏品牌区分隔线的显示，使细分隔线保持清晰稳定。

### 2.2.14 更新重点

- **Windows 标题栏分隔线**：以 1px 右边框绘制品牌区分隔线，并保留亮色主题与 Codex 玻璃主题的颜色适配。

### 本版本包含的主要 PR 和问题修复

- [PR #262](https://github.com/St0ff3l/fileterm/pull/262)：修复 Windows 标题栏品牌区分隔线的显示。

完整变更记录请查看 [v2.2.13 与 v2.2.14 的比较](https://github.com/St0ff3l/fileterm/compare/v2.2.13...v2.2.14)。

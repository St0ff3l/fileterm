## FileTerm 2.2.16

新增六组协调的 iTerm2 风格深浅色主题，并让主题配色完整应用到终端区域和界面操作中。

### 2.2.16 更新重点

- **主题预设**：新增 Catppuccin、Dracula、Gruvbox、Nord、Solarized 和 Tokyo Night 六组深浅色预设，统一放在主题 token 中管理。
- **界面配色**：终端区域边缘渐变、主题预览卡片和主要/危险操作按钮随当前主题变化。
- **主题保留**：更新 FileTerm 后继续使用用户当前选择的主题，不再自动切回 FileTerm 默认主题。

### 本版本包含的主要 PR 和问题修复

- [PR #267](https://github.com/St0ff3l/fileterm/pull/267)：新增 iTerm2 风格主题预设，完善主题配色覆盖并保留升级后的主题选择。

完整变更记录请查看 [v2.2.15 与 v2.2.16 的比较](https://github.com/St0ff3l/fileterm/compare/v2.2.15...v2.2.16)。

## FileTerm 2.2.16

Add six coordinated iTerm2-inspired dark and light themes, with theme colors applied across the terminal area and interface actions.

### Highlights

- **Theme presets**: Add dark and light variants of Catppuccin, Dracula, Gruvbox, Nord, Solarized, and Tokyo Night, managed through the theme token system.
- **Interface colors**: Make terminal edge gradients, theme preview cards, and primary/destructive action buttons respond to the active theme.
- **Theme persistence**: Keep the user's selected theme after updating FileTerm instead of automatically switching back to the default FileTerm theme.

### Main PRs and issues

- [PR #267](https://github.com/St0ff3l/fileterm/pull/267): Add iTerm2-inspired theme presets, complete theme color coverage, and preserve theme selection after updates.

See the [comparison between v2.2.15 and v2.2.16](https://github.com/St0ff3l/fileterm/compare/v2.2.15...v2.2.16) for the complete change set.

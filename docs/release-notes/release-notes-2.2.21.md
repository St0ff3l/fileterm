## FileTerm 2.2.21

改善浅色主题的窗口背景与表面层次，让 FileTerm、Codex 和 iTerm2 配色在连接表单及主窗口中保持一致、清晰。

### 2.2.21 更新重点

- **浅色主题**：为连接表单区分导航、内容分组和输入框表面，提升提示文字及操作区分隔的可读性。
- **iTerm2 配色**：调整 Catppuccin、Dracula、Gruvbox、Nord、Solarized 和 Tokyo Night 浅色表面的明暗层次，同时保留各主题的色温与终端配色。
- **窗口显示**：修复浅色独立窗口透明透底，并让标题栏和标签条沿用当前主题画布色，避免出现突兀的白色区域。

### 本版本包含的主要 PR 和问题修复

完整变更记录请查看 [v2.2.20 与 v2.2.21 的比较](https://github.com/St0ff3l/fileterm/compare/v2.2.20...v2.2.21)。

## FileTerm 2.2.21

Improve light theme surfaces and window backgrounds for consistent, readable layouts across FileTerm, Codex, and iTerm2 themes.

### Highlights

- **Light themes**: Separate navigation, grouped form sections, and input surfaces while improving helper text and action separators.
- **iTerm2 palettes**: Refine light surfaces for Catppuccin, Dracula, Gruvbox, Nord, Solarized, and Tokyo Night while retaining each palette's tone and terminal colors.
- **Window rendering**: Fix transparent bleed-through in standalone light windows and match title bars and tab strips to the active theme canvas.

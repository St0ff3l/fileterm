# iTerm2 配色预设来源

FileTerm 的 Dracula、Nord、Gruvbox、Catppuccin、Solarized 和 Tokyo Night 预设改编自 [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) 中对应的 `.itermcolors` 配色文件。终端 ANSI 色、前景、背景、光标和选区取自上游配色；应用界面的表面层级与状态语义色按 FileTerm 的 ThemeConfig 和 token 链路重新映射。原主题作者信息见上游 [`CREDITS.md`](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/main/CREDITS.md)，配色集合的许可见上游 [`LICENSE`](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/main/LICENSE)。

上游 `CREDITS.md` 记载的原主题作者：

- Dracula：Zeno Rocha
- Nord / Nord Light：Arctic Ice Studio
- Gruvbox Dark / Light：Morhetz
- Catppuccin：Catppuccin 团队
- Solarized Dark / Light：Ethan Schoonover
- Tokyo Night：Folke

# FileTerm 扩展质量检查

## 基线与范围

基于 main `c2354028`，在 `fix/quality-audit` 上继续第一轮[传输路径检查](./transfer-path-quality-audit.md)。本轮审查范围包括：

| 范围                     | 检查方式                                                                | 结果                                                           |
| ------------------------ | ----------------------------------------------------------------------- | -------------------------------------------------------------- |
| 本地文件新建、复制、移动 | Rust 源码审查、临时目录回归                                             | 修复覆盖、递归复制和跨磁盘符号链接丢失；拒绝特殊文件与目标链接 |
| 本地/远端剪切粘贴        | 实际导航 handler + 模拟 IPC 行为测试                                    | 禁止未等待传输完成便删除源文件的跨端剪切                       |
| macOS SMB 生命周期       | 挂载清理源码、临时目录回归                                              | 卸载失败后不再递归删除挂载内容                                 |
| WebDAV/S3 备份           | 共用恢复逻辑、HTTP 分块响应夹具                                         | 修复串口身份冲突、无效配置覆盖、下载内存限额                   |
| 配置存储与凭据           | JSON staging/rollback、profile secrets、日志脱敏审查                    | 本轮未对这些模块另作修改；相关 Rust 测试纳入全量执行           |
| 会话/IPC 同步            | 传输 generation/cancel、snapshot revision、事件取消订阅、锁定计时器审查 | 本轮未确认需要修改的问题；不等于所有竞态均已排除               |
| 前端与发布前质量门禁     | 类型、lint、格式、renderer 构建、CSS 契约、CI 检查                      | 将此前未接入 CI 的 renderer 操作测试纳入门禁                   |

## 本轮修复

1. **跨端剪切过早删除源文件**：上传/下载 command 返回只代表任务已入队。现在跨端剪切直接提示使用复制，不创建传输、不删除源文件、不清空剪贴板。同端剪切仍走原有移动操作。真正的跨端移动须由未来可持久化、验证完成的后端能力承接。
2. **新建文件清空同名文件**：以 `create_new` 原子创建替代空内容覆盖；目标存在时返回错误。
3. **复制自身/子目录**：复制和普通文件/目录移动前解析实际路径，拒绝自身别名、硬链接别名和目标子目录，避免同文件清空及无界递归；最终目标及递归的已有目标条目中的符号链接、硬链接、FIFO、设备、套接字也会被拒绝。移动符号链接保持 rename 操作链接本身的语义。
4. **跨磁盘移动遗漏符号链接**：独立的移动复制路径保留链接本身，不跟随循环链接，支持悬空链接；复制失败或遇到特殊文件时不执行源目录删除。通过 `ErrorKind::CrossesDevices` 判断跨设备错误，替代 Unix 错误号硬编码。
5. **SMB 清理可能删除共享数据**：三个清理入口均只尝试删除空挂载目录；卸载失败后共享内容仍存在时不递归进入。
6. **串口备份合并身份冲突**：串口指纹使用 `devicePath`，同名不同设备不再因空 host/port 被识别为同一连接。
7. **覆盖恢复静默丢弃无效连接**：备份有无效项时拒绝覆盖本地库；合并模式保留有效项并继续报告跳过数量。有效空备份仍遵循用户选择的覆盖语义。
8. **下载限额无法约束分块响应**：WebDAV/S3 共用有界流式读取，在累计超过 5 MiB 时立即终止，不等待响应结束；上传响应缺少新 ETag 时不会保存旧版本标记。
9. **renderer 测试未进 CI**：新增 `test:renderer` 脚本并在 CI 执行，覆盖现有上传批处理和新增剪切粘贴回归。
10. **文件操作名称缺少路径边界**：本地和远端创建/重命名统一拒绝 `..`、路径分隔符和控制字符，避免 IPC 输入越过当前目录；远端父路径统一按 POSIX `/` 解析，Windows 不会误拆合法反斜杠文件名。
11. **S3 合并版本与读取内容脱节**：S3 合并上传现在使用 GET 响应的 ETag 作为条件写入版本，远端在预检后变化时不会把旧内容配上新版本号。
12. **首次日志恢复的锁顺序**：传输日志首次加载与普通持久化统一按日志锁 → 任务锁顺序执行，避免初始化和后台落盘并发时形成死锁；Windows 目录扫描也先检查不跟随的重解析点元数据，单文件上传拒绝符号链接源。
13. **协议下载断点可跟随本地链接**：SSH/SFTP、FTP 与 root 下载共用本地断点打开边界，拒绝符号链接、特殊文件和 Unix 硬链接；Unix 以 `O_NOFOLLOW` 打开，且仅在已打开文件通过类型、链接数和断点长度验证后才清空。最终目标为链接、特殊文件或 Unix 硬链接时也拒绝替换。
14. **TLS 依赖已知漏洞**：锁定的 `rustls` 从 0.23.42 升级到 0.23.45，消除 RustSec 报告的 TLS 1.3 加密层边界校验漏洞；兼容的 `rustls-webpki` 同步升至 0.103.15。

## 验证边界

- 本轮未进行 Windows/Linux 实机测试、签名安装包构建、真实服务器长时间传输或打包 UI 手测；不能据此宣布三平台全面无缺陷。
- HTTP 限额测试使用本机 TCP 夹具，SMB 清理测试使用临时目录模拟残留挂载内容，不操作真实共享。
- 文件路径检查不是文件系统沙箱，不承诺消除其他进程并发改变路径产生的所有竞态。
- 跨磁盘复制失败可能保留已复制的目标条目，源内容保留；没有引入目标目录事务回滚。
- 所有改动源文件均未超过 1000 行；i18n 字典属于规模豁免。新增职责模块放在所属模块目录，原 facade 保持稳定。
- 修改保留本地，未提交、推送、合并、发版或关闭 Issue。

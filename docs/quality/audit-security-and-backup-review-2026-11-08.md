## 二次复查补修

本轮又确认并修复三类边界问题：

1. **独立连接身份被地址指纹合并**：同名、同地址但凭据或分组不同的连接可能被覆盖；重复地址的两份连接在首次覆盖恢复时会从两份变成一份。现在优先匹配本地 ID 和私有备份身份，仅在两侧指纹都唯一时回退到地址匹配；保留独立连接及各自跳板引用。
2. **Linux 继承 ACL 扩大授权**：原文件没有扩展 ACL 时，临时文件可能仍保留目录继承的 ACL；恢复 `0640` 等模式会重新放开其 ACL mask。现在显式清除这类继承 ACL，再恢复原模式。新增 Linux 默认 ACL 用例完成交叉编译，尚未在 Linux 执行；macOS 同类场景已实测通过。
3. **FTP 编辑改变原属主或组**：新临时文件可能属于登录用户的默认组，而原文件属于业务组。现在提交前比较属主/组，无法保留时停止替换，原文件不变，临时内容保持受限权限。

连接恢复额外覆盖重复导入、跨设备再合并和同源不同地址分支。`backupIdentity` 仅用于内部备份匹配，不进入对外快照，普通连接创建/编辑不能写入该字段；新的本地连接 ID 仍重新生成。

连接身份和 FTP 属组回归在修复前共出现 3 个失败断言，修复后通过。最终重新运行完整 `test:local`、严格 Clippy、Rust 格式和 diff 检查，结果均通过；保留原有人工环境跳过项。新增本地保存代码再次通过 Windows/Linux 独立 harness 编译检查。

## 第三轮复审补修

按单用户桌面、多连接及多窗口并发场景补齐四项遗漏：

1. **命令前缀绕过审批**：改为完整匹配固定只读命令白名单。`git log --output`、`find -delete`、复合语句、命令替换及其他参数均交回审批；MCP 同步/后台执行和内置 Copilot 的本地风险分类共用此规则。Git 命令包含可执行外部助手的配置边界，因此不自动放行。
2. **清理传输泄露隐藏连接**：读取列表和清理后的剩余任务共用权限过滤，空清理列表也只能返回可见连接的任务；非法快照明确返回错误。
3. **FTP 提交中断跳过回滚**：上传与校验仍有取消和超时边界，进入替换后等待提交或回滚完成。取消上传后控制流可能残留响应，明确要求重连，不复用已中断的 FTP 控制连接。
4. **连接恢复失败未撤销 SSH 密钥**：在写入依赖前验证 OTP；密钥恢复与连接保存共用失败处理，还原索引和加密口令文件，并删除本次新建的私钥。回滚失败会与原始错误一起报告。密钥读写、导出和恢复使用同一进程内锁，避免回滚覆盖同时发生的口令或密钥变更。

完整复审还修复了相邻的 SFTP 编辑保存路径：上传阶段保留超时及取消，提交阶段不再被外层任务取消；属主或组无法保留时拒绝保存，避免回退到截断原文件。root 保存无法解析软链接目标时也停止并保留临时文件，不再直接覆盖链接指向的内容；root 临时文件创建前设置 `umask 077`，避免继承宽松权限。新建文件复用相同保存链路。

回归覆盖固定命令与绕过输入、两个 MCP 命令入口的审批、连接权限过滤、FTP 提交阶段取消及超过上传期限、SFTP 提交阶段取消/超时与属主不一致、真实文件系统中的密钥索引/口令/新文件回滚，以及 root 软链接解析失败和宽松 shell umask 下创建私有临时文件。失败后的成功导入也已覆盖，防止回滚逻辑影响正常恢复。

严格 Clippy（`--locked --all-targets --all-features -- -D warnings`）、Rust 格式、diff 检查及本文档格式检查均通过。完整门禁日志：`/tmp/fileterm-four-fixes-complete.log`；Clippy 日志：`/tmp/fileterm-four-fixes-complete-clippy.log`。

## 兼容边界与未验收项

- 未启动桌面 UI；未执行 Windows/Linux 原生运行、发行包、真实服务及物理设备验收。Linux Docker daemon 不可用，因此没有 Linux 本机 ACL 运行结果。
- FTP 安全编辑保存要求目录列表、SIZE 和重命名；服务器提供 Unix 权限时还要求 SITE CHMOD。无法保留权限、属主或组时停止保存，失败的远端临时内容可能保留供恢复。
- FTP 编辑拒绝替换符号链接，避免原本的链接被静默改成普通文件；SFTP 与本地编辑保留链接本身并写入实际目标。SFTP 无法保留属主或组、root 无法解析链接目标时拒绝保存。
- FTP/SFTP 编辑一旦进入提交阶段，命令级取消或上传超时不会中断该阶段；调用方可能先收到等待超时，后台仍需等待协议提交或回滚结束。
- 未包含依赖定义的旧备份无法凭空重建代理/隧道；依赖不在本地时明确报错，避免导入不可用配置。旧 v3 加密包和不含私钥的合法明文备份继续可读。
- 超限文件返回错误，编辑器不会拿到可误保存的截断文件。MCP 不新增分页读取接口。
- 当前修改的业务源文件均未超过 800 行；超过 1000 行的两份测试聚合文件属于项目豁免范围。

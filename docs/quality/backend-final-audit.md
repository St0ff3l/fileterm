# 后端专项复核

基于 `fix/quality-audit` 前两轮修复，继续检查 Rust 传输日志、后台操作取消/超时，以及 WebDAV 上传并发控制。

## 确认并修复

### 传输日志损坏被误认为空列表

旧读取逻辑在主日志与备份均读取失败、JSON 损坏或版本不支持时返回空任务。初始化随后将空列表写回，丢失原始恢复线索。

现在仅在日志与备份均不存在时返回空列表；主日志损坏仍可使用有效备份，无法恢复时返回错误并保留原文件。不支持的版本直接报错，避免旧程序回退到旧备份后覆盖新版本数据。

### 历史上限淘汰尚未完成的工作

旧规则按更新时间保留最新 200 条任务，较旧的暂停、失败可重试及待清理任务可能被新历史挤出。

现在所有非终态、可恢复及待清理任务必须保留，剩余空间用于最新可丢弃历史。如果必须保留的任务超过 200 条，日志可以超过该数量，不能为了限制历史而丢断点。

### WebDAV 合并上传覆盖并发更新

旧流程下载内容并合并后，再 HEAD 获取新 ETag 作为 PUT 条件。其他设备在 GET 与 HEAD 之间更新时，新 ETag 会授权写入未包含其变更的旧合并结果。

现在 PUT 使用准备 payload 前观察到的版本：合并使用 GET 返回的 ETag，普通上传使用预检 HEAD 的 ETag，不在提交前刷新。服务端期间变更返回 412 冲突。合并响应没有 ETag 时拒绝上传；PUT 响应缺少 ETag 时不再保存已失效的旧值。

S3 兼容备份同步采用相同的响应处理：合并上传沿用 GET 返回的 ETag 作为条件写入版本，PUT 没有返回新 ETag 时清空本地版本标记，下一次同步重新读取远端版本，不把旧 ETag 当成新对象版本。

### 首次加载与持久化锁顺序

首次恢复传输日志时，加载流程现在先取得日志写锁，再更新内存任务；普通持久化也按同一顺序取得日志锁和任务读锁。这样并发初始化与进度落盘不会互相等待形成锁顺序死锁。

### Windows 本地目录扫描与上传源

Windows 目录扫描在读取目标元数据前先检查不跟随的 `symlink_metadata`，再读取普通元数据，避免 Junction/重解析点先解析到目标目录后逃出扫描树。单文件上传和实际执行阶段也拒绝符号链接源，避免把链接目标当作用户选择的文件写入远端。

### 后台操作超时被误判为用户取消

旧 worker 调用在超时时取消传输共用令牌，外层 `start` 检查该令牌后跳过 `fail_if_running`，可能让任务滞留运行状态。

现在每个 worker 调用从传输令牌派生子令牌：用户取消向下传递，操作超时仅取消本次操作，错误仍进入正常失败/重试路径。请求 future 被丢弃也取消子操作；已取消的请求优先返回，不进入 worker 队列。单文件和目录传输均将子令牌传给实际上传/下载命令。

### 文件操作名称越过当前目录

本地和远端创建/重命名命令此前直接把名称拼入路径，调用方可通过 `..` 或路径分隔符绕过当前目录。现在两侧都要求名称是单个路径组件，并拒绝空名、`.`/`..`、控制字符及本地平台不支持的名称。

远端父目录解析也统一按 POSIX `/` 处理，覆盖 Windows 下的普通远端文件操作、root 上传/替换和刷新路径；远端文件名中的合法反斜杠不会再被当成目录分隔符。

本地复制还会比较源和已有目标的底层文件身份，拒绝指向同一 inode/文件索引的硬链接目标，避免覆盖目标时清空源文件。

复制/跨磁盘移动现在在每一级已有目标都拒绝符号链接、硬链接、FIFO、设备和套接字等特殊文件，避免递归复制在嵌套文件上通过硬链接改写其他路径，或跟随目标链接写入其他位置、打开特殊文件阻塞。

### 协议下载断点跟随本地链接或特殊文件

SSH/SFTP、FTP 和 root 下载都先将数据写入本地 `.fileterm-part` 断点文件。旧流程以可截断方式直接打开该路径：已有符号链接会指向外部文件，FIFO 等特殊文件也可能被打开；Unix 硬链接还可能通过同一 inode 改写其他文件名。

现在三条协议路径共用断点打开边界：拒绝符号链接、非普通文件和 Unix 硬链接；Unix 额外以 `O_NOFOLLOW` 打开以缩小检查后的链接替换窗口。新下载在验证已打开文件的类型、链接数和断点长度后才清空它。最终目标若为链接、特殊文件或 Unix 硬链接，同样拒绝替换，保留断点与原目标内容。

## 回归覆盖

- 缺失日志、损坏主日志、主备均损坏、有效备份恢复、不支持版本。
- 历史数量超过 200 时保留运行/暂停/可恢复/待清理任务。
- 真实本地 HTTP GET → PUT 夹具：下载后服务端版本变化，必须携带下载版本并收到冲突。
- worker channel 夹具：操作超时、用户取消、future 丢弃、请求发送前已取消。
- 本地/远端文件名夹具：创建和重命名拒绝目录穿越输入，同时保留 Unix 合法反斜杠名称。
- 本地递归复制夹具：嵌套目标为 Unix 硬链接时拒绝复制，硬链接的外部文件内容保持不变。
- 本地下载断点夹具：符号链接、FIFO、Unix 硬链接和断点长度变化均被拒绝，外部文件内容保持不变；最终目标符号链接不会被替换。

## 范围与限制

- 复核了传输初始化/写锁、控制调用与数据调用超时、取消收尾、配置库写锁及备份恢复入口；未宣称穷尽全部竞态。
- 异常日志需要修复或从有效备份恢复后才能继续加载任务；应用不再自动覆盖损坏日志。
- 测试使用临时目录和本机协议夹具，未连接真实服务器、未执行断电实验、未做三平台发行包实机验收。
- 本轮修改的业务源文件均低于 800 行，无需拆分；新测试放在传输和本地文件模块目录中。

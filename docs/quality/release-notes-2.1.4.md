## FileTerm 2.1.4

FileTerm 2.1.4 聚焦终端交互修复、跨平台窗口适配、Tauri 发行链路完善与项目工程收口。

### 2.1.4 更新重点

- 终端缩放交互修复：完善触控板手势与终端缩放事件路由，确保缩放操作能够稳定作用于当前终端，并减少与窗口级手势的冲突。
- Vim 复制体验恢复：修复 Vim Visual 模式下的复制操作，恢复多语言文本复制场景，提升终端编辑与选择体验。
- 跨平台窗口适配：限制 macOS 专属红绿灯窗口状态逻辑，避免在 Linux、Windows 等平台触发不适用的窗口行为。
- Tauri 发行完善：补充发行构建所需的窗口配置、平台元数据与版本能力，为 macOS、Windows 和 Debian/Linux 的打包发布提供更稳定的基础。
- 工程与依赖收口：移除不再参与构建和发布的 Electron 历史代码及依赖，锁定关键前端构建依赖版本，并升级 ESLint 与规则体系。
- 社区与平台信息更新：更新社区交流二维码，补充 README 中 macOS、Windows 与 Debian 平台支持信息。

## FileTerm 2.1.3

FileTerm 2.1.3 聚焦 Linux 桌面适配、跨平台界面一致性、连接管理增强与发行质量完善。

### 2.1.3 更新重点

- **Linux 桌面适配完善**：修复 Debian/Linux 下字体度量、数字与中文文字垂直对齐、按钮文字居中、菜单布局和侧边栏排版问题。
- **Linux 发行支持**：内置稳定的中文字体与应用图标，补充 Debian `.desktop` 和 AppStream 元数据，完善安装包在桌面环境中的识别。
- **连接管理增强**：增加资源监控开关与采集间隔设置，支持跳板机路由配置，并改善断线重连、空密码认证等连接场景。
- **命令区域优化**：统一命令列表、历史记录、预览和编辑区域的布局与文字样式，完善暂存及保存到命令管理器的操作。
- **主题与交互统一**：恢复经典概览页按钮 Hover 效果，统一浅色/深色主题下的按钮颜色、下拉控件和导航交互。
- **质量防线加固**：增加 Linux Debian 构建验证，并持续覆盖类型检查、Lint、格式检查、Rust Clippy、协议测试与依赖审计。

### 2.x 重构版包含

- Rust/Tauri 跨平台主运行时、系统托盘、SSH/SFTP/FTP 连接管理器及安全传输中心。
- Windows 签名应用内更新：下载后自动进行包签名校验并重启更新。
- macOS 自动检查更新与 Release 包手动分发。

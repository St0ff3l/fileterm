# Issue #188 / #189 / #180 implementation plan

## Scope

- #188: persist the file-panel ratio per connection configuration, with a
  default-on preference switch under Settings → Interface.
- #189: cancelled. Remote items are intentionally not dragged out to the host
  file manager or desktop; FileTerm-internal pane dragging remains supported.
- #180: keep the existing base-theme plus override model, then add native font
  import as a separate follow-up slice with UI and terminal font slots.

## #188 design

- The persisted key is `ui.file-panel-preferences.v1` in the existing Tauri
  UI-state store. Its value maps `profileId` to `{ ratio }`.
- Ratios are clamped to `0..50`; `0` means hidden and non-zero values are
  converted to pixels only after the current workspace size is known.
- New connections use a 30% default. The effective pixel height is capped at
  half of the workspace and also leaves room for the terminal area.
- Drag updates remain renderer-local. Only mouse-up, hide, and show write a
  ratio, so dragging does not produce a write storm.
- The preference switch is persisted with `UiPreferences` and defaults to on.
  Turning it off ignores saved connection ratios without deleting them.

## #189 design

- FileTerm file rows use an app-local pointer gesture for cross-pane transfers:
  local → remote calls the existing upload path and remote → local calls the
  existing SFTP/FTP download path. System file managers receive no local path
  or native file promise, so dragging a remote item outside FileTerm is a
  no-op and cannot start a download.

## #180 design

- Preserve `baseThemeId` and per-variant theme inheritance already present in
  the core model.
- Add native `.ttf/.otf` import into the app data directory with metadata and a
  content checksum; never persist the source path.
- Expose imported UI and terminal font slots separately and register imported
  font data through renderer-owned `@font-face` rules. Reuse the existing
  canvas/xterm metric observer when the terminal font changes.
- Do not add arbitrary CSS injection.

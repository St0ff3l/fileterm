# 表格列宽跟随布局记忆开关

- 复用 `filePanelRememberRatio` 开关和现有 `getUiStateItem` / `setUiStateItem` 存储边界，不新增后端命令或独立设置。
- 按连接 profile ID 与稳定表格 ID 隔离文件、网络、系统信息列宽。拖动结束/键盘调整时保存，读取校验列数、有限数值和范围，关闭记忆时不读取/覆盖既有记录。
- 共享布局作用域与 hook，来源会话保持原 profile；拆分窗格中的文件区用自己的 profile 覆盖作用域。网络/系统表格使用稳定 ID，避免语言切换和数据刷新改变存储键。
- 检查重新挂载/重开连接、不同连接与表格隔离、关闭开关、重置文件列宽、异步读取不覆盖刚拖动的值、保存顺序及原有拖动行为。

## 完成与验证

- 工作区提供统一的布局作用域，文件管理器按自己的 profile 覆盖来源；每个网络/系统表格使用稳定 ID，文件区保留原默认列宽与重置操作。
- 设置文案更新为“记住面板比例与表格列宽”。打开时，指针拖动结束或键盘调整后使用既有 UI state IPC 持久化；关闭后不恢复、不写入，并保留此前记录供再次开启时恢复。
- 每个键的写入串行执行，重新挂载先等待未完成保存；读取结果不会覆盖开始读取后发生的拖动。重置存为默认记录，旧重置计数不会在重新挂载时抹掉之后的新列宽。
- 新增 4 项 storage 测试验证键隔离、损坏/旧版/越界数据、写入顺序与重新读取、失败恢复和重置。Renderer 共 290 项通过。
- 浏览器验证拖动过程中不写入、结束仅写一次、页面刷新/重新挂载恢复、连接与表格隔离、开关关闭后的恢复/写入禁用、延迟读取不覆盖新拖动、文件嵌套连接作用域和重置后的再次调整。
- 类型、lint、Prettier 和 CSS contract 通过；未实际重启 Tauri 桌面进程验证，浏览器存储夹具不替代原生持久化验收。

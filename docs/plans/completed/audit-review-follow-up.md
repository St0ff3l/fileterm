# 审查遗漏补修：命令、传输与恢复事务

状态：实现、完整本机门禁与最终复审完成；跨平台原生及发行验收待进行。

沿用当前 `fix/audit-security-and-backup` 分支及已有未提交修复，补齐第三轮审查发现的四项问题：

- 自动执行只允许完整匹配的固定只读命令，复合 shell 和其他参数交回审批。
- MCP 清理传输与读取传输共用连接权限过滤。
- FTP/SFTP 编辑上传阶段保持取消和超时，替换与回滚阶段等待完成；SFTP 属主/组不一致及 root 软链接目标无法解析时停止保存，禁止直接截断回退；root 临时文件创建前限制 umask。
- SSH 密钥恢复与连接保存共用失败回滚，恢复旧索引、口令并移除新建私钥；密钥读写串行，避免回滚覆盖并发修改。

回归：审批策略、受限传输响应、FTP 协议夹具在提交中取消/超时、真实文件系统上的密钥及口令回滚。

验收：完整 `npm run test:local`、严格 Clippy、Rust 格式和 diff 检查；重新审查修改与相邻调用链。Windows/Linux 原生、真实远端与打包 UI 验收继续单独列明。

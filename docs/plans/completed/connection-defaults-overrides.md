# SSH 连接默认值与连接级配置

状态：已完成

## 目标

把连接编辑器中的 SSH 高级选项提升为可复用的全局默认值。全局值只在新建连接时填入，已有连接始终使用自己保存的配置。

## 已完成

- 在 `UiPreferences.connectionDefaults` 中持久化 SSH 全局默认值：空密码认证、Exec 通道、资源监控及采集间隔、断线行为、旧算法兼容。
- 保留 SSH profile 中可选的 `connectionOverrides` 以兼容旧数据；新建和编辑流程不再写入或展示覆盖来源选择。
- 设置页新增“连接默认值”；新建连接表单直接使用当前全局默认值。
- 连接编辑器高级页只展示并修改当前连接自己的配置，不再显示“设置来源”下拉框。
- 编辑旧 profile 时将其局部覆盖或历史字段转换为表单中的具体值；保存后连接跟随自己的已保存配置。
- Rust 会话启动、重连、资源监控、CWD 注入和远程 Exec 命令均使用解析后的有效值。
- 关闭 Exec 通道时保留终端、SFTP 浏览和隧道，跳过依赖 Exec 的平台探测、CWD 注入和资源采集，并拒绝远程 Exec 命令与 root 文件视图。

## 生效范围

修改全局默认值不会影响已有连接或已经运行的会话，只对之后新建的连接生效。已有连接需要进入编辑页修改并保存后，才会使用新的连接级配置。

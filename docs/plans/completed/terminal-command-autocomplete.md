# Issue #389：终端内命令候选

Refs #389。FileTerm 直接复用 Fig 开源规则，终端适配、上下文解析、候选面板与 SSH 文件整合自行实现；参考 Netcatty 的规格加载、提示符恢复和多级候选体验。Issue 保持开放，代码合入不表示发布验收通过。

## 实现

- 固定构建依赖 `@withfig/autocomplete@2.692.3`；构建脚本提取 1,472 份声明式规格，其中顶层命令 715 个。12 个函数型/版本选择定义跳过。保留多级子命令、选项别名、持久选项、互斥/依赖选项、参数建议、文件模板与静态 `loadSpec`。
- 离线规格按命令懒加载；生成 JSON 不提交 Git，开发、类型检查、renderer 测试和打包入口自动重建，已有内容不重复写入，避免触发无关 HMR。源码、版本与生成脚本共同保证可复现。
- 修复首次连接/已有提示符/热更新后没有新 OSC 7 时无候选的问题。普通 shell 提示符从 xterm 恢复，实时 OSC 7 支持自定义提示符；接受前严格核对普通屏幕、行尾和远端回显。无关偏好广播和 resize 不清除当前行的资格。
- 支持 `docker `、`docker compose `、`docker container `、`docker compose up --`、`sudo docker …`、带参数的选项与引号/转义、管道之后的命令。完整命令名或子命令已匹配时，也可直接预览下一层候选。
- 每个 SSH 窗格独立维护输入、选中项与请求。上下键选择，Tab/点击只追加候选后缀，不发送回车；Esc 关闭、无候选和设置关闭时透传远端按键。
- 文件建议走已有只读 `listRemoteDirectory`，不改变文件面板。请求去重、缓存和版本检查拒绝过期结果；文件失败不影响规格/历史来源。复用已有连接历史，不额外记录原始终端输入。
- 高级设置中的“使用 FileTerm 命令候选”在新安装和旧数据迁移时均默认开启，即时保存生效；关闭后停止 FileTerm 候选与相关按键接管，使用远端终端自身的补全。
- 已添加 [Fig 致谢、来源与许可证](../../../THIRD-PARTY-NOTICES.md)；应用系统信息页也展示来源、固定版本、完整 MIT 许可和 Fig 链接。上游包元数据标 ISC，实际分发 LICENSE 为 MIT，完整保留实际版权声明。

## 验证

- 12 项补全专项测试覆盖实际 Fig Docker 多级规格与选项、包装命令、选项参数、引号、路径转义、无 OSC 的已有 Docker 提示符、无关偏好广播、resize、回显延迟、过期目录结果、设置、键盘/点击和窗格隔离；验证转换不调用生成器、版本固定及许可证完整保留。
- 当前源码的真实 TerminalView/xterm 浏览器检查：初始提示符不含 OSC，输入 `docker ` 显示 58 个候选；`docker compose up --` 显示 20 个对应长选项；Tab 接受只发送后缀，无回车/换行。此前已检查 Esc/关闭设置透传、浅色/深色及窄视口定位。
- 类型、lint、Prettier、全量 280 项 renderer 测试、Rust/contract、Clippy、CSS contract 与 renderer 生产打包为完成门禁；结果以本次执行报告为准。CSS contract 原有 12 处 `!important`、约 6 处 legacy 颜色债务没有扩大。

- 候选描述允许完整换行，命令列约 28%，面板宽度 520px（受视口限制）；浮层高度按可用空间限制，向上展开使用实际内容高度锚定，避免固定单行高度估算裁切多行说明。浏览器检查截图中的七个命令，描述均无横向溢出，`cap` / `capacitor` 的长说明完整换行。

## 尚未覆盖

- Fig 的脚本/函数型动态生成器尚未启用：例如实时容器名、镜像名、Git 分支和部分需 CLI 版本检测的规则。不能把静态规格覆盖数视为完整 Fig 引擎兼容性。
- 不猜测 Shell/SFTP chroot 映射；无法确认 CWD 命名空间一致时跳过路径。未知提示符且没有实时标记、多行编辑/自动换行、变量/命令替换、密码/REPL 和备用屏幕保持远端处理。
- 真实 SSH、原生中文输入法和三平台桌面仍待实机验收。已识别本项目的开发进程与 Vite 端口，但 Computer Use 未提供可精确绑定该未打包进程的目标，因此没有操作安装版代验。

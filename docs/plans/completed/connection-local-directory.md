# 每个连接的本地默认目录

日期：2026-11-12。Related to #369 的后续目录反馈。

## 行为与边界

- SSH/SFTP/FTP 连接在远程路径旁增加“本地目录”，输入框提示说明这是此连接默认打开的目录，留空使用系统默认目录。
- `BaseProfile` / `CreateProfileInput` 增加可选 `localPath`；表单回填、共享存储转换和现有 Rust JSON profile 保存链路保留该值，无需修改 IPC 命令。
- 本机目录初始化从 workspace hydration 移至独立 hook，避免启动时默认目录请求覆盖连接配置目录。
- 本次运行中按标签保留浏览位置，关闭标签释放缓存；重新打开连接或重启应用后使用已保存的默认目录。修改默认目录会使旧浏览缓存失效。
- 不可用目录显示错误并回退到系统默认目录；旧标签的迟到请求不覆盖新标签。
- 收藏目录的含义不变。目录路径随连接配置保存，跨设备恢复后不可用时走同一回退流程。
- 收藏面板的当前目录卡片提供“设为默认目录”；本地面板写入该连接的 `localPath`，远程面板写入 `remotePath`，由 profile 快照同步到连接管理器。

## 验证

自动回归覆盖：按标签切换并保留浏览目录、目录失效回退、迟到响应隔离、修改配置后缓存失效，以及 SSH/SFTP/FTP 编辑表单回填。

人工验收：给两个连接分别设置不同的本地绝对路径，保存并重启应用；依次连接，确认左侧目录正确。浏览子目录并切换标签，确认位置保留；删除或撤销默认目录访问权限后重新连接，确认提示并回退。

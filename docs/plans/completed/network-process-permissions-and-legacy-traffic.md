# 网络进程权限与旧版流量兼容

- `bytes_sent` 优先；缺失时回退旧版 ss 的 `bytes_acked`，通过 `txBytesSource` 标记来源，界面解释“对端已确认字节”的口径。缺失字段继续显示 —，不推算成零。
- 新增固定用途 `ReadNetworkConnections` worker 请求，不接受任意命令或来自 renderer 的提权参数。
- SSH worker 复用会话当前的文件访问身份：普通模式走登录用户，已启用 root/sudo/su 的模式复用既有身份及认证；8 秒超时、独立 exec 通道，轮询不抢终端输入。FTP/Telnet 不支持该能力。
- 测试覆盖旧版多行 acked、现代 sent 优先、明确零与缺失，以及原有权限/协议回归。真实群晖需在 SSH 终端 sudo -i 完成认证、确认 root 模式同步后刷新验收。

网络页工具栏复用现有 root 认证弹窗的 sudo/su 切换入口，并显示当前目标用户；与同会话文件区共享权限状态。身份切换后立即重新采集，底部说明缩短并保留旧版 acked 口径。

同会话有可复用 sudo 认证时，再次切换直接请求复用；认证失效才退回现有弹窗。两枚网络工具按钮默认和 hover 直接复用确认弹窗次级按钮 token，root 不绘选中底色。双击非交互空白清除 socket 选择，刷新保留取消状态。回归覆盖重复点击、认证失效、空白取消与刷新。

系统/网络表格的选择范围限定到文字内层（inline-block），保留结构层的原生文字选择以兼容 WebKit 触摸板点按拖选，紧凑文字内层避免跨格出现半行空白高亮；表头拖动手柄保持不可选。

网络排序表头使用可选文字的 span 按钮角色，原生按钮不再拦截触摸板点按拖选；拖选释放不排序，普通点击及 Enter/Space 仍排序。已用浏览器实际组件验证普通拖选、点按后拖选和键盘排序，未替代 macOS 原生触摸板实测。

# 目录上传卡住排查

2026 年 11 月 17 日收到外部用户反馈，上传约 150 MB 的目录时卡住。反馈设备的日志尚未取得，故障阶段和原因待确认。

- 本地目录条目使用一次不跟随链接的元数据读取确定类型、大小和修改时间。保留对符号链接、Windows Junction 和其他不受支持类型的拒绝。
- 单次本地扫描 I/O 等待超过 30 秒时，返回包含操作和路径的错误。正在执行的系统调用可能继续占用后台线程，超时后扫描流程会退出。
- 按传输 ID 记录目录准备开始、结束和文件阶段结果。逐文件开始事件使用 Trace，已有失败和重试日志继续记录。
- macOS 上通过 TypeScript 类型检查、ESLint、Prettier、Rust 格式检查、Renderer 测试、Rust/contract 测试和 Clippy。扫描测试覆盖超时、嵌套文件和链接拒绝。反馈设备、原服务器和 Windows 重解析点需现场验证。

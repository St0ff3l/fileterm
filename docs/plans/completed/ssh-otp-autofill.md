# SSH OTP 自动填写（Refs #375）

- 目标：连接保存可清除的 Base32 OTP 密钥，SSH keyboard-interactive 对明确的动态验证码提示自动提交 TOTP（SHA-1 / 6 位 / 30 秒）。
- 边界：复用 profile-secrets 加密存储及公开存在标记；密钥与验证码不进入快照/日志。保存、编辑、测试连接、重连、跳板、备份保持既有路径。
- 防误填：只匹配明确 OTP 提示，不自动回答短信、邮件、恢复码或推送问题；每次认证最多自动提交一次，后续提示交回手动输入。
- 验证：RFC 6238 向量、密钥校验、保存/替换/清除/脱敏、真实本地 SSH 协议夹具（成功、错误密钥、重复提示回退），项目质量门禁。
- 验收说明：新增用户可操作的 MFA 测试文档；不修改真实 SSH 服务器配置。

- 同类调研：检查 guopeizhao 的 36 个公开 Star，未确认截图出处；参考 OxideTerm 的唯一匹配、一次尝试与发送前生成策略，保留 FileTerm 现有凭据边界。自定义识别使用不区分大小写的普通文本，避免增加正则配置复杂度。
- 交互测试：提供显式启动的 `otp_manual_fixture`（仅 loopback、临时端口、公开测试密钥），平时测试忽略，不进入产品构建。

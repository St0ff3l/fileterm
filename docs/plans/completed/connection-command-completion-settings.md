# 连接命令候选设置

- 将独立的高级设置页移入“连接默认值 → 高级设置”，并在连接编辑的高级设置中提供对应开关。
- `SshConnectionDefaults.terminalCommandCompletion` 默认开启，仅用于新建连接；连接保存独立值。旧连接缺少值时开启，不跟随后续全局默认值变化。
- renderer 命令候选监听 workspace snapshot 中当前 profile 的配置；保存后已有终端立即更新。保留旧 UI 偏好字段供数据兼容，但不再作为运行时总开关。
- 连接默认值说明单行显示，空间不足时横向滚动。
- 验证覆盖当前连接切换、旧连接默认开启、不同连接隔离，以及默认值序列化与解析。

## JavaScript 与生命周期

- feedback-bubble.tsx：通知重排，240ms ease-out 曲线 → 共享 move 时长与 ease-in-out，取消旧补间后从当前位置接续。
- use-app-workspace.ts：工作区切换调度，240ms，与既有 CSS 时长保持同步；已有首页标签不重播动效的保护保留。
- system-network-panel.tsx：requestAnimationFrame 绘制实时采样，不作为界面过渡改造。
- 终端 resize、滚动、字体测量等 requestAnimationFrame 属于调度，保留原有行为。

## 实现结果

1. 原有减少动态效果适配之外，补齐全局 hover/位置过渡与状态呼吸、锁定错误摇晃；减少动态效果模式保留颜色/透明度反馈。
2. 缓动与时长 token 分离，迁移 CSS 默认 ease 和散落的 cubic-bezier，旋转与传输进度保留 linear；审查到的 transition: all 均改为明确的绘制/transform 属性。
3. 连接编辑导航使用同一选中背景，180ms ease-in-out 可中断补间；内容 180ms 短淡入，不移动点击目标。
4. 下拉菜单按实际展开方向进入，180ms 入场、150ms 退出；退出表面 inert，立即重开取消移除；原生 macOS select 路径保持原有行为。
5. 分段控件使用同一选中背景；主题、hover、选项变化和缺失选项回退均保留，窗口/控件尺寸变化仅重新定位，不播放移动动画。
6. 侧栏与文件面板的既有布局过渡统一为 180ms ease-in-out，拖拽仍为无缓动；终端现有水平调整冻结列与稳定后重排机制继续生效。grid 仍承担真实空间分配，不通过缩放终端文字模拟布局。

公共弹窗与下拉菜单使用当前帧采样处理进退场中断；通知重排取消旧补间并保留当前位置。旧 dialog CSS 路径改为导入 canonical 样式，避免两套动效分叉。

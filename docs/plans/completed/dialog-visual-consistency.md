# 弹窗视觉一致性

## 目标

以连接 SMB 网络共享为基准，盘点并统一所有应用内弹窗及独立窗口内容标题区域的高度、背景、图标、标题字体和正文背景。保留原生窗口按钮、拖拽区及关闭处理链。沿用当前本地改动，不提交或推送。

## 步骤

1. 枚举组件与样式，测量 SMB 基准并归类差异。
2. 在公共样式与语义变量中收敛外观，迁移各弹窗覆盖项。
3. 使用真实组件与合成数据生成全部变更类型的深色预览，同时验证浅色、窄窗口与交互状态。
4. 运行项目门禁，交付清单与预览索引。

## 完成结果

- SMB 基准：标题栏 44px，标题 13px / 500，图标 16px，左右留白 16px。背景、文字、图标统一通过四个 dialog 语义变量映射主题；公共 `dialog-chrome.css` 统一覆盖入口，移除冲突的旧背景优先级。
- 旧式差异涉及运行时隧道、连接/命令编辑器、密钥导入/备注、路径收藏、文件冲突、导入预览以及管理器/设置弹窗；此前分别存在 48px 标题、侧栏背景、不同标题字重与图标颜色、卡片内边距等覆盖。
- 共验证 33 种组件变体：SMB 凭据与共享选择、root、sudo 密码、SSH 登录与多轮认证、主机指纹首次/变化、私钥口令、备份密码、新建/重命名、权限、冲突、收藏、运行时隧道、代理与隧道配置、命令与连接编辑、连接导入、密钥导入与备注、调用详情、MCP 审批、删除/关闭确认、便携更新、文件编辑器、连接/命令管理器、设置、异常详情。
- 连接编辑器接入 FormDialogBody；命令编辑器复用 VerticalScrollbar 并将操作区移出滚动内容。760×680 下两者保持 24px 上下安全留白，底部操作可见。
- 预览保存在 `docs/quality/dialog-previews/`：33 种组件 × 深浅主题，共 66 张原图、两个总览及可筛选 HTML 索引。60 组表单样式及 6 组普通确认模板样式核对通过。
- 代码文件均未超过 1000 行；本次两个编辑器分别为 507 / 293 行，不需拆分。CSS、i18n 与文档按仓库规则豁免。

## 验证与范围

- typecheck、lint、全量 Prettier、renderer 247 项测试、Rust/contract 测试、Clippy、CSS contract 与 diff whitespace 检查通过。Rust 既有交互式 OTP 测试保持忽略。
- 浏览器加载真实组件与合成数据，无保存或真实连接副作用；深色使用当前用户主题，浅色使用 FileTerm Light。Monaco 浅色初始化曾有一次 ResizeObserver 通知，未影响截图及布局。
- 主页内嵌管理器、原生独立窗口标题栏及 macOS 按钮校准不受应用内弹窗高度规则影响。未操作原生窗口，未验证 Windows/Linux 或真实 SSH/SMB 交互。
- 预览文档已按用户要求本地提交；UI 源码继续保留工作区修改，未推送。
- 范围纠正：普通 ConfirmActionDialog 的关闭、删除、便携更新等提示保持原有 18px / 650 标题与 24px 留白；表单覆盖仅显式应用于 external-operation-confirmation、ssh-key-import-dialog，不再改变确认提示模板。
- 全量复核 30 个调用点（27 个普通确认、3 个表单变体）。删除父弹窗的 dialog-surface 局部重定义以避免嵌套继承；真实确认组件 60 组禁用/启用新样式对比，无计算样式差异、无新增规则命中。详见预览 README。

# 监控恢复、侧栏遮罩与启停控制

状态：实现完成。

## 目标

- 监控短暂失去数据不禁用能力、不清空历史、不折叠侧栏。
- 遮罩显示暂停、最后更新时间、恢复倒计时、尝试次数和手动重试。
- 五档间隔 I：暂停 max(15, 3I)，重建 max(60, 5I)，首次数据 max(30, 3I)，单位秒。
- 重建阈值从最后有效数据计，达到后立即第 1 次；明确通道结束等待 2 秒。
- 最多 5 次恢复，后续退避 5/10/20/30 秒；手动跳过等待，不重复启动。
- 恢复收到有效数据立即显示；持续正常 60 秒且至少 3 个样本才重置额度。
- 关闭/断开取消恢复；会话代次与事件版本拒绝旧任务写入。
- 保留平台、PTY 和交互网关限制；监控通道恢复不重连终端。

## 断开恢复与启停交互

- `disconnected` 不隐藏恢复操作：监控任务退出显示“监控已断开 / 立即重试监控”；会话断开或后端明确标记 `ssh-disconnected` 时显示“SSH 连接已断开 / 重新连接 SSH”。
- SSH 重连复用 `reconnectTab`，连接中禁用按钮，失败保留重试和错误反馈。
- 父监控管理任务持有 SSH 上下文和 retry receiver，等待采集子任务完成；异常退出后仍可手动启动新的采集任务，不自动无限重启。
- 子任务退出后以快照中的 generation/revision 恢复状态；新采集须在旧任务退出后启动，保留历史并标记曲线断点。
- 侧栏提供关闭／启动监控按钮，与隐藏按钮组成竖排工具组，间距 6px、距右侧 10px，在地址区域整体垂直居中，并共用背景、边框、圆角及悬停样式；遮罩从地址区域下方开始，恢复收到有效数据后撤去遮罩。
- 手动关闭监控会取消采集及重试，不修改连接配置；同一标签 SSH 重连后保留手动关闭状态。会话关闭或取消会清理管理任务。
- 配置中的监控关闭立即取消采集，并同步旧会话的监控不可用状态，避免重新开启配置后将缓存数据展示为实时数据；重新开启配置或修改采集间隔后，新连接使用新配置。这与侧栏的运行时启停按钮区分。
- 监控开关和遮罩使用不同 React key，避免状态切换后残留旧按钮。
- 启停按钮统一使用细线电源图标，与隐藏图标保持相同尺寸和线宽；停止时图标降低亮度，仍可点击启动。
- 启停命令等待采集任务确认状态切换后返回工作区快照，界面直接应用返回值，不依赖单次状态事件结束加载。后台确认最多等待 15 秒，前端请求最多等待 20 秒；失败结束转圈并保留错误反馈。
- 停止确认在采集通道清理结束后发出；启动确认表示采集任务已启动，首份有效数据仍由遮罩等待。
- SSH 终端已就绪、平台探测或 SFTP 初始化尚未完成时，也可停止或重新启用监控。此时命令确认的是已保存的启停意图；采集任务沿用同一代次，安装控制器时读取该意图，不会忽略提前停止。
- 打开采集通道超时或取消后，独立清理任务仍接收迟到的通道并关闭；同一采集管理任务只允许一个尚未完成的打开请求，避免重试堆积。清理任务不会主动重连或断开 SSH，迟到通道关闭或 SSH 结束后释放资源。
- 隐藏侧栏、切换标签或界面等待超时后，命令返回的工作区状态仍会应用；旧快照由工作区版本校验拒绝。遮罩的监控重试与 SSH 重连请求也有 20 秒等待上限，超时结束转圈并提示检查当前状态。
- 提前停止后在采集任务首次运行前启动，也必须先发布启动确认再采集；所有启动入口共用同一段生命周期逻辑。
- SSH 认证或 shell 初始化期间关闭监控配置，后续会话初始化会保留禁用状态；只有新建或重新连接的会话才按新配置重新启用。
- 迟到的成功结果会清除对应操作的错误并关闭对应确认弹窗；操作序号隔离新旧请求，旧结果不能清除新错误或关闭后来打开的弹窗。

## 监控操作文案

- 电源按钮统一使用“停止监控 / 启动监控”，确认弹窗明确仅影响监控采集和自动重试，不主动断开或重连 SSH 终端。
- 遮罩的整会话恢复入口明确写为“重新连接 SSH”，并说明包括终端；监控通道恢复继续使用“立即重试监控”。
- 首次启动显示“正在启动监控”，退避期间显示“等待重试监控”；不将首次启动称为重试。
- 重试耗尽说明本轮额度已用完、尚未稳定恢复，避免误称全部为自动重试或期间从未收到有效数据。
- 启停错误说明“未能确认监控状态”，避免在请求超时但后台可能完成时误报确定失败。
- 中英文同步更新，类型、Lint、格式和浏览器交互检查通过；当前便携包尚未包含此次文案调整。

# 深色悬停灰阶

FileTerm 和 Codex 深色共用 RGB (42, 42, 42) 的悬停灰阶。主页主导航和设置分类侧栏沿用 RGB (48, 48, 48) 的选中与悬停底色。

受影响的共享样式包括以下位置。

- 常规次要按钮、无底色工具按钮，以及弹窗的取消按钮。
- 网络页的权限切换、刷新、连接列表行和系统侧栏的网络详情按钮。
- 连接配置的新建代理与隧道、AI 的新建 Provider、添加模型、刷新列表和测试连接。
- 文件、目录树、路径收藏、传输列表，以及连接、命令和密钥管理中的通用灰色悬停。
- 下拉菜单选项、窗口工具、终端搜索和终端底部工具中的通用灰色反馈。

依赖共享悬停值的混合底色也随基础灰阶更新。浏览器已验证深浅主题的共享按钮与两个侧栏，并刷新深色取消和网络工具栏悬停截图。

## 实现与验证

- 页面直接使用后台会话的单栏卡片、表头和空状态，记录总数进入 HomeWorkspace 共用页脚。
- 标题、侧栏与空状态统一使用新的本地 call-log SVG。24px 坐标系内仅两条横线，间距 6px；18px 侧栏尺寸下保持清楚留白。
- 新 CSS 全部使用语义变量，CSS contract 从原 PR 的两项阻塞变为通过；仍有仓库既有非阻塞警告。
- 隔离浏览器夹具复用真实 HomeWorkspace 和样式，API 使用合成数据。深浅主题的卡片宽高、表头高度、背景色与边框色和后台会话一致。
- 65 条记录分两页加载，期间插入新记录，游标仍返回 65 个原有条目，页脚更新到 66 条。验证读取失败保留现有列表，复制失败保留弹窗并提示错误，成功后关闭弹窗。
- 860px 窄窗口中表头与行列对齐，列表没有横向溢出，总数固定在底部。
- 新增两项 renderer 回归覆盖实际审批/执行标签及目标摘要；SVG 资产测试通过。
- 类型、lint、Prettier、246 项 renderer 测试及 Clippy 通过。Rust 单元 940 项、CLI 10 项和 contract 23 项通过；既有交互式 SSH OTP 手工夹具保持 ignored。
- 原生桌面窗口、真实主机及 Windows/Linux 未进行手工验收。临时浏览器夹具在验证后移除。

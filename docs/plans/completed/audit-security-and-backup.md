# 审查问题修复：审批、备份与文件安全

状态：实现、完整本机门禁与复审完成；跨平台原生及发行验收待进行。

目标：修复 2026-11-08 全项目审查中的七项问题，保留既有协议和数据兼容性。

- MCP 审批由桌面策略决定，不信任客户端的审批开关。
- 备份快照与连接保存共用连接库锁；网络请求和密码等待不持有该锁。
- 本地和 FTP 编辑保存采用临时文件及可回滚提交。
- SFTP 编辑临时文件创建时即限制权限，权限设置失败禁止提交。
- 备份恢复和云端合并重映射跳板连接引用。
- 加密备份包含连接引用的代理、隧道及必要凭据，恢复时保留本地配置。
- 文件读取在协议层有界；超限不把截断内容当作完整文件交给编辑器。

影响：Rust commands/services/sessions、备份兼容格式、协议夹具和回归测试。

验收：类型、lint、Prettier、renderer、build、Rust/contract、Clippy、Rust 格式；完成后复审最终调用链和失败路径。

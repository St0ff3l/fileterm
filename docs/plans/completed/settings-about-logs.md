# 设置中的关于、日志和开源致谢

- 设置侧栏提供独立的「日志」和「关于」入口，搜索词分别覆盖诊断与版本、许可。
- 日志页顶部提供日志目录入口，下方保留现有基础日志与分类开关。关于页收紧运行时信息和第三方项目的间距。
- 按用途列出主要开源项目，离线展示现有项目声明、随包资产清单以及 iTerm2 配色来源。项目链接使用桌面外部链接桥接。
- Chromium 用模拟桌面桥接验证了中文深色、英文浅色、窄窗口排版、搜索切换、键盘展开、打开目录回调和分类开关。原生开发窗口无法由预览工具精确绑定。
- 类型、Lint、Prettier、CSS contract、Renderer 测试、Rust/contract 测试、Clippy 和 Renderer 生产构建通过。

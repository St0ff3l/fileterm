# 标签切换时保持侧栏宽度

本轮方案已根据用户澄清修订为[标签独立宽度与一致的细边框](sidebar-independent-widths.md)，以下保留 `a8a9d64f` 阶段的实现记录。

- 当前改动先提交为 `d663534a`，本次只修复侧栏宽度和终端右侧边框过渡。
- 根因：主页对保存宽度施加视口上限，普通连接页直接读取保存宽度；右侧 12px 装饰边框条件挂载且没有动画。
- 统一普通布局下主页与会话页的实际展开宽度及拖拽上限，保留保存宽度与主机分组的独立侧栏。
- 右侧边框常驻，用宽度和透明度过渡控制显隐，遵守减少动态效果设置。
- 验证：增加切换宽度及边框过渡回归检查，运行项目质量门禁；桌面验证只绑定当前项目开发进程。

## 完成与验证

- 普通布局下主页、连接页与标题栏统一使用视口约束后的展开宽度，拖拽使用相同上限；保存宽度仍在视口恢复时还原。
- 终端边框常驻，通过 240ms 宽度和透明度过渡显隐；开启减少动态效果时立即切换。主页、本地终端、文件传输页、主机分组和 AI 面板仍隐藏此边框。
- `npm run typecheck`、`npm run lint`、全量 Prettier 检查、CSS contract、221 项 Renderer 测试、927 项 Rust/contract 测试及 Clippy 均通过。CSS contract 的 11 处 `!important` 和约 6 处旧颜色警告与修改前一致。
- Chromium 布局回归覆盖四主题、三平台样式的 36 次标签切换，以及过渡中间帧、反向切换、减少动态效果；另外 264 个窗口控件/AI 面板布局场景通过。平台样式检查不等于对应操作系统实机验证。
- 当前项目开发进程和 Vite 5188 已识别，但桌面工具应用清单不含未打包开发进程，无法精确绑定，未操作或启动其他 FileTerm 版本替代验证。

## 2026-11-17：退出时的上下边角残影

- 切到主页时外层标签栏所在行归零，常驻右侧装饰边条立即移到新的 grid row 起点，而 180ms 宽度/透明度过渡还未结束，因此右上角会短暂出现边条，底角也会留下同一条边框的末端。
- 关闭时保留边条宽度和透明度过渡；主页状态将边条裁剪到原工作区上下边界，避免折叠的标签栏和底部行在动画中留下额外装饰段。
- 在现有 `sidebar-tab-switch.mjs` 增加回归：三平台样式、四主题、带/不带自绘菜单栏、本地/远端终端共 48 组退出，检查过渡中间帧、上下裁剪和反向打开恢复 12px。
- 原有侧栏/终端边框切换浏览器矩阵、264 组 AI 面板和窗口控件布局、286 项 renderer 测试、类型、lint、格式与 CSS contract 通过。未验证原生桌面窗口动画。

# 设置操作浮动提示

## 范围

WebDAV/S3、会话安全、本地终端 Shell、AI Provider 与主题操作结果统一使用公共 FeedbackBubble；静态帮助、初始加载错误和普通确认模板保持原样。

## 最终样式

- 根据用户反馈重新设计浮动提示卡片（参考简约 Alert / Shadcn 设计）：右下侧固定悬浮（距右 40px、底部 96px），卡片采用自适应紧凑尺寸与 12px 内边距，背景使用右键菜单的语义色。
- 极简视觉层级：左侧为独立的单色状态图标（纯色 check / close / info，无额外半透明圆形底色），标题 13px、说明 12px，图标与标题行垂直居中。边框使用统一的中性低对比边框，去除额外彩色描边。
- 复用公共 CloseButton：右侧关闭按钮复用公共组件 `CloseButton`（compact 尺寸），悬停使用危险态红色；支持 4s 自动关闭（鼠标悬停暂停、移出恢复，错误/警告保留手动关闭）。160ms 平滑入场与 140ms 渐隐离场动效。
- body portal 不占正文空间；长文本完整换行、超高内容复用公共滚动条。删除锚点 ref、位置计算、滚动/尺寸监听器及失效的定位测试。

## 验证

- 自动测试检查无消息不渲染、portal 挂载、完整文本及状态保留。
- 现有 renderer 测试覆盖无消息不渲染、portal 挂载、完整文本及状态保留；此前完整门禁已通过，本轮本地终端反馈迁移后未重跑。
- 用户要求不再反复浏览器验证，未进行本轮浏览器或原生桌面视觉验收。
- 本计划随本轮改动提交，未推送。

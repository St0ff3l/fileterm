# 界面字号缩放

状态：实现完成；Windows 2K、100% 缩放的真实设备画面尚未验收。

## 实现

- 在「外观与布局」增加独立的界面字号比例，默认 100%，范围 80%–150%，每档 10%。
- 复用现有 UI 偏好 IPC、持久化与多窗口同步；整体界面缩放、终端字号和 Monaco 代码字号保持独立。
- 界面缩放与界面字号会叠加，综合文字倍率限制在 200%，设置页显示当前综合倍率；降低界面缩放时恢复所选字号效果。
- renderer 的固定字号通过 CSS 变量应用；Material Symbols 图标和 xterm 输出保持原样。
- macOS 在字号变更后重校准原生标题栏布局。

## 验证

- 旧配置默认 100%，Rust 对越界值归一化；Renderer 字号缩放测试覆盖比例和边界值。
- 类型、Lint、Prettier、Renderer、Tauri Rust、Clippy 和 CSS 契约门禁通过。
- Windows 2K 实机布局未在当前 macOS 环境验证。

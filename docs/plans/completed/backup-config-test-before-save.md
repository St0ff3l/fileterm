# 备份配置保存前测试

状态：实现已完成（2026-11-21）

## 目标

WebDAV 与 S3 连接测试使用设置表单中的当前值，不要求先保存；测试失败或成功都不写入新配置，也不修改远端备份。

## 实施范围

- Renderer 将 WebDAV/S3 当前表单字段和用户本次输入的密钥传入测试 IPC。
- Rust 将输入合并到已保存配置上，以便空白密钥字段沿用已保存密钥；复用保存时的字段归一化与验证。
- 只发起现有的连接预检请求，不持久化临时配置。

## 验收

- 可对尚未保存的地址、路径和凭据执行连接测试。
- 已保存密码/密钥在表单留空时仍可用于测试。
- 测试不会保存配置；既有协议错误和连接成功反馈保持不变。

# Noto Sans SC

FileTerm bundles the unmodified variable font from Google Fonts for the Linux
renderer so Simplified Chinese text uses stable glyph metrics across Debian
installations.

- Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
- License: SIL Open Font License 1.1 (`OFL.txt`)
